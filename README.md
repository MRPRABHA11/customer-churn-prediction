# Customer Churn Prediction Project Kit

Intermediate portfolio project: Python + SQL (SQLite) + Machine Learning + Power BI.

## Dataset
Download the IBM Telco Customer Churn CSV from:
- Kaggle: https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- IBM sample documentation: https://www.ibm.com/docs/en/cognos-analytics/12.1.x?topic=samples-telco-customer-churn

Place the CSV in `data/` and name it `WA_Fn-UseC_-Telco-Customer-Churn.csv`.
If your filename differs, pass it as an argument:
`python churn_project.py --data "data/your_filename.csv"`

## Setup (Windows)
1. Install Python 3.10+ and optionally VS Code.
2. Open a terminal in this folder.
3. Create a virtual environment:
   `python -m venv .venv`
4. Activate it:
   PowerShell: `.venv\\Scripts\\Activate.ps1`
   CMD: `.venv\\Scripts\\activate.bat`
5. Install libraries:
   `pip install -r requirements.txt`
6. Run:
   `python churn_project.py`

## What the code does
1. Loads and validates the CSV.
2. Converts `TotalCharges` to numeric; blank values become missing and are imputed inside the model pipeline.
3. Performs simple EDA.
4. Splits data into stratified train/test sets.
5. Trains Logistic Regression using preprocessing pipelines to avoid leakage.
6. Evaluates with precision, recall, F1, ROC-AUC, confusion matrix, and baseline accuracy.
7. Retrains a scoring model on all labeled rows and exports risk probabilities for dashboard demonstration.
8. Loads cleaned data and predictions into SQLite.

## Important evaluation note
The test metrics come from a held-out test split. The exported customer risk scores are generated by a final model fitted on all available rows; these scores are for demonstrating a workflow, not a prospective production forecast. This is a cross-sectional sample, not a time-ordered dataset. A real deployment should use time-based validation on later periods, calibration, monitoring, privacy controls, and a retention experiment to estimate whether interventions actually reduce churn.

Create a relationship from `cleaned_customers[customerID]` to `churn_predictions[customerID]` (one-to-one for this dataset).
